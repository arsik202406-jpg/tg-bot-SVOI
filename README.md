# SVOI Travel — Telegram-бот + Mini App

Бот @Svoi_TravelEU_bot для поездок по Европе на Opel Vivaro: клиенты бронируют места в боте или в Mini App, а все заявки, места и адреса хранятся в базе.

## Что умеет

**Клиент** (тексты бота на украинском):
- «🗺 Поїздки та дати» → тур → дата → сколько человек → места на схеме салона (или «будь-які вільні») → откуда забрать → адрес → телефон кнопкой → проверка → готово.
- Адрес и телефон запоминаются: в следующий раз бот предложит «та сама адреса?».
- «📝 Мої бронювання» — свои поездки, отмена в 2 нажатия.
- Любое сообщение, написанное текстом или голосом, уходит менеджеру. Ответ менеджера (Reply) приходит клиенту от имени бота.
- Mini App (кнопка «Забронювати» слева от поля ввода): те же 5 шагов, светлая и тёмная тема.
- 🎲 «Розваги»: 5 викторин и Колесо Фортуны (один оборот на человека, выигрыш приходит админу).
- Чистый чат: старые экраны и нажатия кнопок удаляются сами. Подтверждения брони, ответы менеджера и помощника остаются.

**ИИ-помощник** (если задан `ANTHROPIC_API_KEY`):
- Отвечает на вопросы клиентов по базе знаний `bot_code/data/faq.md`, каталогу и реальным датам.
- Собирает данные и создаёт **заявку**. Подтверждаешь её только ты, кнопкой.
- Если не знает ответа, клиент недоволен или просит человека, передаёт разговор тебе. Ответь через «Ответить», и помощник замолчит в этой переписке на 6 часов.
- Включается и выключается кнопкой в `/admin`. Модель задаётся в `AI_MODEL` (по умолчанию `claude-haiku-5-5`).

**Админ** (`/admin`):
- 🚐 **Рейсы и пассажиры**: по каждому рейсу полный список пассажиров по городам с адресами, телефонами, местами и суммой, схема посадки, таблица Excel.
- Подтвердить или отменить заявку: клиент получает сообщение.
- ➕ **Добавить даты**: тур → `28.11, 5.12`. Людям из листа ожидания бот сам напишет, что даты появились.
- 📨 **Написать всем пассажирам рейса** (например, «завтра забираем в 5:30»).
- ➕ **Добавить пассажира вручную** (если человек позвонил).
- 📢 **Анонс в канал** с кнопкой «Забронювати».
- 🖼 **Фото туров**: отправьте боту своё фото, и оно появится в боте и в Mini App.
- 🔒 Закрыть или открыть набор, 🗑 отменить рейс (пассажиры получат уведомление).
- 🎁 **Розыгрыши** в группе и канале: бот проверяет подписку на канал, считает участников, выбирает победителя и публикует итоги.
- 🧠 **Викторина** в группу или канал (опрос с правильным ответом).
- 🖼 **Фото и видео**: приветствие после /start (фото, логотип или видео), альбом мини-вэна, фото туров.
- Новых участников группы бот приветствует коротким сообщением с кнопкой «Поїздки та дати».
- 🗺 **Маршрут сбора**: рейс → «Маршрут і час збору». Бот находит самый быстрый порядок адресов от твоего дома до места, считает время назад от прибытия (по умолчанию 11:00) с 1–2 остановками по 15 минут, 5 минутами на посадку и запасом. После «Затвердити» каждый пассажир получает своё время. С `GOOGLE_MAPS_API_KEY` расчёт идёт по Google с учётом пробок, без ключа — бесплатно по OpenStreetMap.
- ✅ Накануне в 14:00 (примерно за 15 часов) бот просит каждого подтвердить участие. Отказ освобождает места и оповещает лист ожидания. В 21:00 ты получаешь список тех, кто не ответил.
- ⚠️ За 3 дня до поездки, если людей меньше `MIN_PAX` (5), приходит предупреждение.
- ⭐ Отзывы: на следующий день после поездки бот просит оценку и пару слов. Ты одобряешь, после этого отзыв виден клиентам; можно опубликовать в канал.
- 💶 Отметка оплаты у каждого пассажира, сумма собрано/осталось. 📊 Статистика (только для админа).
- 🎁 «Запросити друга»: личная ссылка, бонус за первую поездку друга — бесплатный выбор места обоим.
- 🔒 Политика конфиденциальности (`/privacy`, текст в `bot_code/data/privacy.md`), `/delete_my_data`. Телефоны и адреса удаляются через 6 месяцев после поездки.
- 💾 Каждое воскресенье в 20:00 бот присылает резервную копию всех броней.
- Клиент может предложить свою дату. Она приходит менеджеру, а клиент попадает в лист ожидания.

Одно место нельзя продать дважды: это проверяет база.

## Настройка (один раз)

### 1. База данных Neon (бесплатно, данные не пропадают)
1. Зарегистрируйтесь на https://neon.tech и создайте проект (регион Frankfurt).
2. Нажмите **Connect** и скопируйте строку вида `postgresql://...neon.tech/neondb?sslmode=require`.

> На бесплатном Render диск стирается при каждом обновлении. Без Neon все брони пропадут.

### 2. Render → ваш сервис → Environment
| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | новый токен от @BotFather |
| `DATABASE_URL` | строка из Neon |
| `ADMIN_IDS` | `8450153980` (ваш ID; можно несколько через запятую) |
| `ANTHROPIC_API_KEY` | ключ Claude API (необязательно, для ИИ-помощника) |
| `GOOGLE_MAPS_API_KEY` | ключ Google Routes API (необязательно; маршрут с учётом пробок) |
| `MIN_PAX` | минимум людей для поездки (по умолчанию 5) |
| `ARRIVE_TIME` | во сколько быть на месте (по умолчанию 11:00) |
| `ROUTE_BUFFER_MIN` | запас времени в маршруте, минут (по умолчанию 10) |

Build Command: `pip install -r requirements.txt` · Start Command: `python main.py`.
Если в Render указан Root Directory `bot_code` и команда `python bot.py`, это тоже работает.

### 3. GitHub Pages (Mini App)
Собирается автоматически при каждом пуше в `main` (Actions). Адрес сервера бот сам передаёт в Mini App, ничего настраивать не нужно.

### 4. Канал
Добавьте бота администратором в канал, иначе он не сможет публиковать анонсы.

## Где что лежит
- `bot_code/data/trips.json` — **все туры** (названия, цены, программы). Одна точка для бота и Mini App.
- `bot_code/handlers/client.py` — бронирование для клиентов, `admin.py` — админка, `support.py` — вопросы.
- `bot_code/services.py` — логика брони, список пассажиров, уведомления.
- `bot_code/api.py` — API для Mini App (проверяет подпись Telegram).
- `src/` — Mini App (React).

## Локальный запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN
python main.py
# Mini App: npm install && npm run dev  → http://localhost:5173/?demo
```
